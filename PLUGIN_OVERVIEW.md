## Работа с партнёром

Подготовьте доступ к модели, подключите аккаунт svaib в BB и продолжайте работу с AI-партнёром в выбранной папке. Плагин показывает настройку Kimi, кабинет и серверный конструктор структуры управленческого пространства. Карточка клиентского раздела может открывать настроенную веб-ссылку.

## Начало работы

Для Kimi откройте карточку на странице svaib и выберите Claude Code или Pi. Для нового доступа нужен API-ключ из консоли Kimi Code. Путь Pi использует штатную установку и фактический профиль; рабочие подключения и другие провайдеры сохраняются. Отдельная среда исполнения остаётся явным резервным вариантом. Карточка проверит ответ выбранной модели; во время настройки видны текущий этап и прошедшее время.

После ответа модели нажмите «Подключить svaib». Партнёр поможет пройти вход и проверить аккаунт, затем продолжит поручение в выбранной папке. Один методологический пакет Harness подходит для Codex, Claude Code и Pi и обновляется независимо от BB. Работающие подключения сохраняются; разница версий сама по себе не мешает продолжать работу.

## Личные настройки

Выберите стартовый экран, порядок вкладок и видимость временных панелей. Кабинет и показатели сохраняют настройки отдельно для аккаунта; вид график/таблица и показ плана запоминаются для каждого показателя.

## Требования

Нужны BB Desktop 0.48.1 или новее с совместимым SDK, аккаунт svaib и отдельный доступ к модели. Для Kimi нужны отдельная подписка и API-ключ, для Pi — подходящий Node.js22+ с npm. Недостающий Pi можно установить через BB. Для Claude Code и резервного пути Pi доступна отдельная переносимая среда исполнения. Модели и глубина рассуждения выбираются в BB; доступ зависит от тарифа, Highspeed расходует больше квоты. Для методологических обработчиков нужен Python 3.10+. Подтверждение структуры в конструкторе само не создаёт файлы: их подготавливает и проверяет агент.

Версия раннего доступа. Исходники и изолированные проверки не заменяют полного пути нового пользователя. Новый мастер с настоящим ответом Kimi и клиентские Windows/macOS проходят отдельную приёмку.
