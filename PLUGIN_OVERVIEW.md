## Работа с партнёром

Подготовьте доступ к модели, подключите аккаунт svaib в BB и продолжайте работу с AI-партнёром в выбранной папке. Плагин показывает настройку Kimi, кабинет и серверный конструктор структуры управленческого пространства.

## Начало работы

Для Kimi откройте карточку на странице svaib: она проверит Node.js, примет ключ, подготовит отдельный профиль Claude Code и предложит проверочный разговор. Настройку можно повторно открыть в настройках плагина. Уже работающий доступ к другой модели сохраняется.

После ответа модели нажмите «Подключить svaib». Партнёр поможет пройти вход и проверить аккаунт. Один методологический пакет Harness0.10.0 подходит для Codex и Claude Code; его native-установка обновляется отдельно.

## Требования

Нужны BB Desktop 0.48.1 или новее с совместимым SDK, аккаунт svaib и отдельный доступ к модели. Для Kimi нужны отдельная подписка/API-ключ и Node.js22+ с npm; при отсутствии Node карточка покажет ссылку на установщик. Для методологических обработчиков нужен Python3. Подтверждение структуры в конструкторе само не создаёт файлы: их подготавливает и проверяет агент.

Версия раннего доступа: новый установленный путь Kimi и Windows/macOS ещё проходят живую приёмку.
