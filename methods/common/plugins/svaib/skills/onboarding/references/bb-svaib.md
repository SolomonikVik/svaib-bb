# svaib в BB

Цель — открыть партнёра на своём компьютере, подключить svaib и подготовить папку материалов компании. Помощник в Telegram ведёт тебя до первого разговора в BB; затем агент компьютера берёт техническую подготовку на себя. Известные сведения и готовые подключения сохраняются.

## 🔹 1. Открой BB

Назови помощнику ОС и то, что уже установлено. Он подскажет подходящий способ: приложение, а для Intel Mac — запуск BB в браузере. [Шаги установки](bb-and-omp.md).

На виртуальном Linux-столе тоже запускается BB Desktop/AppImage. Уже скачанный файл сохраняется; подтверждения входа выполняются в браузере внутри этого стола.

**Результат:** BB открывается на твоём компьютере.

## 🔹 2. Подключи доступ к AI

Помощник предложит варианты и обсудит их с тобой. Для нового доступа из РФ основной путь — [Kimi через Claude Code](kimi-cc-bb.md): сначала установить BB-плагин svaib через меню, затем пройти встроенный настройщик. Для него ещё не нужны агент и вход в svaib. Если выбран Pi или Claude Code ограничен ОС, используй [Kimi через Pi](kimi-pi-bb.md): в справке есть проверка доступности карточки и ручной запасной путь. Подробные шаги для каждого варианта описаны в его инструкции. Покупать подписку Claude или ChatGPT для этого не нужно.

Если подходящий Codex или Claude Code уже работает, сохраняем его. Для отдельно выбранной подписки используй штатную кнопку **Install**, если агент ещё не установлен, и подтверди вход в браузере. Не отправляй пароли и ключи в сообщениях.

В мастере **Agent → Projects → Plugins → Devices** кнопка **Continue** ведёт дальше. Необязательные разделы можно пропустить через **Skip**, затем нажать **Start using bb**. Если экран отличается, расскажи помощнику, что видишь: он подскажет ближайшее действие.

Добавь локальную папку как проект. Если папка компании уже есть на компьютере, используй её; иначе выбери отдельную пустую папку. Существующие файлы сохраняются.

Если настройщик Kimi уже подтвердил проверочный ответ, повторять его не нужно. Если выбрал другой доступ, выбери подключённую модель в разговоре BB и отправь:

> Привет. Ответь одной фразой, что ты готов к работе.

**Результат:** модель ответила в BB. Доступ к AI работает; теперь подключаем svaib.

## 🔹 3. Передай настройку агенту компьютера

Telegram-помощник даст готовый запрос: что уже установлено, какой доступ выбран и что делать дальше. После карточки Kimi открой **обычный новый разговор** с выбранной средой — Kimi (CC) или Pi — той же моделью и выбранной локальной папкой и передай запрос туда. Служебная «Проверка Kimi» предназначена только для короткого теста модели. Повторять тест, создавать другой профиль или заново покупать доступ не нужно. С другим уже работающим агентом можно продолжить в его обычном разговоре. Источник для новой установки и обновлений — [npm-пакет svaib для BB](https://www.npmjs.com/package/bb-plugin-svaib-workplace).

Если расширение уже установлено для настройки Kimi, агент проверит его и использует, сохранив работающий источник установки. Если нет — установит штатным способом BB из `npm:bb-plugin-svaib-workplace`. Пакет уже собран; отдельно ставить Git или npm не нужно. Общий пакет svaib для Codex, Claude Code и Pi входит в поставку с поддержкой Pi; его native-установку и MCP агент проверяет отдельно. Для Kimi (CC) он использует CLI Claude в том же фактическом изолированном профиле Kimi, сохраняя провайдер и модель. Для Pi используются native-пакет и MCP того же профиля Pi; команды marketplace Claude к нему не относятся. Если источник временно не открывается, помощник сохранит текущий шаг и поможет разобраться, не заменяя его другим пакетом.

Если установка требует подтверждения источника или хуков, агент объяснит, что устанавливается, и продолжит подключение здесь. Сохраняются известные аккаунт, компания, папка, материалы и договорённости; повторно составлять запрос не нужно. Если после подключения инструменты svaib не появились в текущей сессии, агент подготовит один новый разговор для проверки и передаст туда поручение.

**Агенту BB:** плагин может быть установлен внутри текущего разговора, а новые скиллы и инструменты в нём ещё не видны. После установки найди `svaib-workplace` через `bb plugin list --json`, проверь ID, источник и `rootDir` по согласованному источнику; работающую установку сохрани. Прочитай `experiments/account-prototype/skills/svaib-workplace-connect/SKILL.md` внутри этого проверенного `rootDir` напрямую. Выполни его передачу через доступный `svaib_connect_start` либо описанный там публичный CLI/RPC fallback: точные project/thread возьми из self-контекста BB, пакет `continuation` подготовь сам из исходного поручения и Telegram-сводки. Сохрани объём задачи, ожидаемый аккаунт, выбранные компанию/папку, материалы, ограничения, договорённости и ближайший шаг; неизвестное не заполняй. Человек не готовит JSON, не переносит команды и не начинает знакомство заново.

**Результат:** расширение svaib доступно в BB.

Если устанавливаешь расширение через меню самостоятельно: **Settings → Installed plugins → New plugin → Install from source**, затем вставь `npm:bb-plugin-svaib-workplace` и подтверди показанный источник. После завершения открой страницу svaib. Терминал для этого не нужен.

## 🔹 4. Подключи свой аккаунт svaib

Продолжай с текущим агентом: он проверит уже работающие входы и выполнит недостающее. Подтверди вход в браузере под тем же аккаунтом, с которым начал в Telegram. В виртуальном столе используй браузер внутри этого стола. Если для появления инструментов агент подготовил новый разговор, перейди по выданной ссылке и продолжай там.

Если установил расширение самостоятельно и передача из разговора ещё не запускалась, на странице svaib нажми **«Войти в svaib»**. После входа используй **«Продолжить»** у нужного шага. Если продолжение уже открыто, используй его ссылку: повторный запуск подключения не нужен.

Не нужно переносить коды, токены и итоговый адрес страницы в терминал. Если для проверки нужен свежий разговор, плагин передаст туда поручение и договорённости автоматически. Если переход непонятен, текущий помощник даст ссылку и проведёт по одному действию; заново входить в работающий аккаунт не нужно.

**Результат:** агент действительно обратился к svaib и сообщил, под чьим аккаунтом работает; кабинет подключён к тому же аккаунту. Проверь имя. Установленный пакет или закрытая страница входа сами по себе этот результат не подтверждают.

## 🔹 5. Подготовь материалы компании

Агент прочитает общее продолжение настройки и профиль. Он уточнит только недостающее, поможет выбрать существующую компанию или создать свою по твоему поручению. Для новой компании нужны название, короткое описание и согласованный адрес латиницей. Это регистрационные сведения, а не подробный опрос о стратегии и целях.

Для выбранной компании и папки агент предложит структуру в конструкторе BB или обсудит её с тобой в разговоре. В конструкторе можно изменить дерево и передать пожелания агенту. Он обсудит их, подготовит тексты, согласует чувствительные изменения, создаст разрешённые файлы и прочитает их для проверки. Действие в конструкторе само по себе не создаёт файлы и не разрешает затирать существующее.

**Результат:** выбранная компания, согласованная структура и созданный, проверенный каркас в твоей папке.

После создания и проверки каркаса продолжайте в этом разговоре: партнёр прочитает правила пространства и перейдёт к знакомству. Новый разговор нужен, если после подключения не появились инструменты svaib. После штатного выбора другой папки партнёр может продолжить здесь, проверив её привязку. Если нужная папка уже открыта здесь и подключение работает, переходить не нужно. Поручение и результат партнёр передаст сам; возвращаться в старый разговор за ними не потребуется. Отдельно: для работы с другой уже подключённой компанией нужен чистый разговор.

Следом — профиль сотрудника, его зона ответственности и первая полезная задача, выбранная вместе с ним. Большой опрос о стратегии и целях для этого не требуется. Локальная читаемая папка достаточна для старта. Материалы могут оставаться на Диске, в Notion или другой системе. Серверный источник для Telegram/почты, обмен изменениями с компьютером и доступ коллег настраиваем отдельно, в зависимости от выбранной цели; `not_connected` источника не означает неисправность локальной папки.

## 🔹 Если остановились

Напиши в Telegram или агенту BB, что видишь и что уже получилось. Помощник продолжит с этого шага. Заново регистрироваться, покупать подписку или повторять установку без причины не требуется.

Доступные обновления расширения показывает BB. После его обновления агент проверит и при необходимости обновит пакет выбранного движка из той же поставки. Повторно получать архивы и выполнять ручную сборку не нужно.

Чтобы вернуться позже, достаточно:

> Где я остановился? Что дальше?
