# Рабочее место и подключение пространства

Веди человека по одному шагу. Сначала проверь, что уже подключено; после перерыва продолжай с текущего состояния. Повторять уже выполненные приглашение, вход, подключение папки и настройку доступов не нужно.

## Рекомендуемое рабочее место

**Для нового пользователя из РФ — GetBB + Kimi через Claude Code.** Эта связка не требует зарубежной карты и VPN; по нашему опыту, CC проще настроить и Kimi лучше работает через него в наших сценариях. Подробный путь — [Kimi через Claude Code](kimi-cc-bb.md). Если человек выбрал Pi или этот движок ограничен его ОС, используй [Kimi через Pi](kimi-pi-bb.md): сначала проверь доступный способ настройки, затем веди по нему.

- **GetBB** — приложение для разговора с партнёром и работы с файлами.
- **Claude Code** — движок, через который партнёр читает материалы и выполняет поручения; для Kimi отдельная подписка Claude не нужна.
- **Kimi** — модель по подписке Kimi Code. Для K3.1 Pro с контекстом 1M выбираем Pro; перед оплатой проверяем цену в аккаунте.

Перед настройкой обсуди доступные варианты: для нового доступа из РФ предложи Kimi как основной, а уже работающие Codex/Claude — как возможность продолжить без новой покупки. Выслушай предпочтения и вопросы, объясни разницу в оплате и подготовке и выбери путь вместе с человеком. Рекомендация по умолчанию не обязывает переходить на этот вариант. Другие подтверждённые связки не перенастраивай ради неё. За пределами РФ учитывай доступные человеку подписки.

## Первый запуск и оплата

BB бесплатен, доступ к модели оплачивается отдельно. Для новой подписки по умолчанию выбирай оплату за один месяц. Цены и комиссии в инструкциях не фиксируй; искать их на официальном сайте можно по просьбе человека. По умолчанию отдельный поиск цен не нужен. Перед оплатой человек проверяет период, валюту и полную сумму списания за месяц на экране оформления. Для Kimi используем международный сайт, подписку с Kimi Code и ключ из консоли Kimi Code; Open Platform — отдельный продукт. Оплата из РФ и безопасный ввод ключа описаны в [инструкции Kimi](kimi-cc-bb.md). Технические настройки хранятся в ней.

Для выбранного Kimi сначала ставим BB и плагин svaib через меню, затем используем встроенную карточку настройки Kimi. Она работает до первого агента и входа в svaib: готовит выбранную среду и проверяет ответ. Claude Code получает отдельный профиль; Pi сначала использует штатную установку и существующий профиль. Telegram-помощник ведёт по экрану; человек выполняет только показанные ручные операции, для которых нет API. Если подходящий агент уже работает и человек выбрал его, настройку svaib продолжает этот агент. Для Claude Code подробные шаги — в [инструкции Kimi (CC)](kimi-cc-bb.md). Для выбранного Pi — в [справке Pi](kimi-pi-bb.md): она отдельно описывает новую карточку и ручной запасной путь, доступный до её выпуска.

Другие модели и агрегаторы подключаем по отдельному выбору человека. Техническая справка для стороннего провайдера Codex/OMP — [отдельная инструкция](codex-omp-providers.md); она не является обязательным шагом основного пути.

### Другие варианты доступа из РФ

Оригинальная подписка Claude — путь к Claude через Claude Code, подписка ChatGPT с доступом к Codex — путь к GPT через Codex. Оба агента штатно доступны в BB: для выбранной подписки используй установку и вход по [общему маршруту BB](bb-svaib.md). Если агент уже работает, продолжай с ним.

Если человеку нужны именно модели Claude или GPT, можно обсудить рублёвые API-агрегаторы. Они дают доступ к моделям по расходу токенов, а не подписку Claude или ChatGPT; запросы и рабочий контекст проходят через агрегатор и поставщиков модели. До пополнения проверяют условия работы с данными и цену выбранной модели. Подключение именно к BB и совместимость с плагином svaib у этих вариантов пока не проверены.

- [RouterAI](https://routerai.ru/) — первый кандидат: сервис описывает [Codex](https://routerai.ru/pages/vibe-coding-codex) и [подключение агентов](https://routerai.ru/docs/guides/overview/agent-installer), заявляет модели Claude и GPT и оплату из РФ. На [Startpack](https://startpack.ru/application/router-ai/reviews) много отзывов, в том числе жалобы на стоимость и расчёт расходов. До выбора проверь, какие ограничения расходов доступны; цены ищи только по просьбе человека; оплата и работа на рабочем месте клиента нами не проверены.
- [Polza AI](https://polza.ai/) — альтернатива: сервис заявляет оплату картой РФ и СБП, модели Claude и GPT, инструкции для [Claude Code](https://polza.ai/claude-code) и [Codex](https://polza.ai/integrations/codex). Найденных [отзывов](https://sites.reviews/businesses/polza.ai) мало, среди них есть жалоба на ошибку и поддержку; собственную проверку не проводили.

Если человек хочет оплачивать оригинальную зарубежную подписку, можно сравнить варианты ниже. Условия доступны на сайтах сервисов; это не проверенные нами платёжные маршруты.

- [Wayment](https://wayment.net/) — карта для подписок; сервис заявляет Claude, ChatGPT и пополнение по СБП. На [Отзовике](https://otzovik.com/reviews/wayment-virtualnaya_karta/) шесть отзывов, включая жалобу на курс и комиссии: выборка мала для уверенного вывода.
- [Kardo](https://kardopay.com/cards/) — карта для подписок; сервис заявляет Claude, ChatGPT и пополнение по СБП. Независимых отзывов для уверенного вывода не нашли.
- [MIG Pay](https://migpay.app/) — пополняемая карта; сервис заявляет пополнение по СБП и инструкции для Claude и ChatGPT. [Сторонний обзор](https://zarubcard.ru/karty/mig-pay/) не нашёл независимой площадки отзывов и отмечает, что курс и часть условий раскрываются при оформлении. До покупки уточни условия возврата остатка и комиссии.
- [МТС Оплата](https://payment.mts.ru/tools/claude) предлагает разовую оплату Claude; [МТС также заявляет ваучеры](https://moskva.mts.ru/about/media-centr/soobshheniya-kompanii/novosti-mts-v-rossii-i-mire/2026-04-29/mts-zapustila-prodazhi-podarochnyh-vaucherov-na-zarubezhnye-servisy) для Claude и ChatGPT. Наличие и цену сейчас подтвердить не удалось; разовая оплата не означает возможность автоматического продления.

Перед оплатой человек проверяет полную стоимость выпуска, курс, комиссии, продление, возврат и условия конкретной карты на экране оформления. Не запрашивай у человека пароль или коды доступа.

Зарубежная карта не снимает региональные ограничения самих сервисов: РФ отсутствует в списках доступности [Claude](https://support.claude.com/en/articles/8461763-where-can-i-access-claude) и [ChatGPT](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries); доступ из неподдерживаемого региона может привести к ограничению аккаунта. Не обещай, что оплата или дальнейшая работа пройдут успешно.

## Что где находится

- **Партнёр svaib** помогает руководителю думать и работать с учётом контекста компании.
- **Управленческое пространство** — связанная информация о работе руководителя и бизнеса: документы, подключённые источники и системы, встречи, решения, задачи и показатели. Его каркас — обычные markdown-файлы, разложенные так, как бизнесом управляют. Это общая память команды; карта каркаса — корневой README.
- **Рабочее место** — приложение за компьютером, где человек работает с агентом: GetBB + Kimi через Claude Code для нового пользователя из РФ; другие работающие подходящие связки сохраняются. Плагин svaib даёт рабочие сценарии (скиллы), а подключение MCP — данные и инструменты серверной части svaib.
- **Личный диалог с ботом в Telegram** — разговор с серверным партнёром с телефона. Он подключается при регистрации по приглашению.
- **Telegram-группа для отправки** — дополнительный адресат сообщений, например группа команды. Её добавляют, когда человек хочет получать сообщения в этой группе.

При желании используй Obsidian для ручного чтения и редактирования файлов. Агент и Obsidian открывают одну папку; файлы между компьютерами синхронизирует выбранное хранилище.

## Подключение

1. Начни с регистрации и личного помощника svaib в Telegram. Компания, BB и готовая папка для этого не нужны. Помощник выяснит выбранный путь и уже сделанное, поможет с установкой приложений и доступом к модели.
2. Когда агент рабочего места доступен, продолжи с ним в выбранной папке. Для BB используй [единый маршрут подключения](bb-svaib.md); агенты — Claude Code, Codex и выбранный Pi с пакетом svaib; особенности Pi — в [его справке](kimi-pi-bb.md). Для выбранного Claude Desktop — [установка и вход](claude-desktop-svaib.md). Вход в агент или модель проверяется отдельно от входа в MCP и кабинет svaib.
3. Агент прочитает профиль того же аккаунта, уточнит только недостающее и поможет выбрать существующую компанию либо создать реальную компанию по поручению: название, технический адрес и короткое описание. Название компании не доказывает права; доступ проверяет сервер.
4. Для выбранной компании проверь выбранную человеком папку и прежние материалы. Готовое пространство используй; новый каркас согласуй в разговоре или необязательном Screen-конструкторе и создай через `space-scaffold`, затем прочитай файлы. После проверки пространства продолжи знакомство: профиль сотрудника → зона ответственности → первая полезная работа. Углублённые интейки стратегии и целей можно провести позже.

Продолжение настройки сохраняется в общем профиле аккаунта: рабочий агент прочитает известные сведения и начнёт с незавершённого шага. Агент ведёт четыре группы: подготовить партнёра, войти в svaib, подключить компанию и пространство, познакомиться и начать работу. Проверенное подключение отмечает сразу, до каркаса. Screen использует доступный канал показа — браузер или адаптер рабочего места; его отсутствие не мешает согласовать каркас в разговоре.

Отдельную Telegram-группу предлагай только для отправки сообщений в неё. Личный помощник уже доступен после регистрации; не проси пройти этот шаг заново.

## Пространство

Получи объявленную папку и проверь существующие материалы. Если человек выбрал конструктор, покажи структуру через доступный серверный Screen. Screen собирает намерение. Агент обсуждает его с помощью `space-scaffold`, готовит точные тексты, согласует необходимые изменения и применяет их файловыми инструментами. Различие версий структуры само по себе не блокирует работу; актуальность намерения, права и состояние файлов проверяются перед записью. Проверяй результат чтением созданных файлов: подтверждение дерева не создаёт их, не разрешает затирать существующее и само не закрывает этапы онбординга.

После первого создания и проверки `AGENTS.md`, `.svaib/` и каркаса продолжай в текущем разговоре: прочитай корневые правила и переходи к первому непройденному этапу знакомства. Поручение, проект, окружение и компания сохраняются. Повторная установка, вход и конструктор не нужны.

`.svaib/platform.json` хранит настоящий стабильный ID выбранной компании. Выбор компании и доступ проверяются через MCP; привязку пишет помощник онбординга. До создания каркаса отдельный файл привязки может ещё отсутствовать; это не основание подставлять фиктивный ID. Существующая повреждённая привязка не исправляется автоматически. У одного человека могут быть отдельные папки и чаты разных компаний; смена компании в Telegram не переключает текущую папку. Перепривязка требует явного выбора и нового чистого чата.

Локальная читаемая папка достаточна для начала работы. Серверный источник для Telegram/почты, обмен изменениями с компьютером и доступ коллег — отдельные задачи по цели человека. `not_connected` источника не означает неисправность локального каркаса. Перед настройкой прочитай выбранную справку ниже; инструкция внешнего плагина описывает его операции и не заменяет маршрут svaib. Для общей работы хранилище выбирает компания; сотрудник подключается к принятому варианту. Приглашение коллеги через MCP не предоставляет ему права на файлы автоматически. Обычные локальные файловые поручения не требуют регистрации фиктивной компании; серверный конструктор в выбранном маршруте требует реальной компании и проверенного доступа.

Когда человек подключает пространство к серверному партнёру, проверь `workspace_source_status`, если инструмент доступен. Если его нет, серверное подключение пространства пока недоступно; локальное чтение не доказывает доступ серверного партнёра. `ready` означает успешную серверную синхронизацию; при ожидании или ошибке продолжай с указанного серверным инструментом шага.

- [Google Диск](drive.md) — для работы с обычной папкой и привычным предоставлением доступа.
- [git](git.md) — если команда умеет им пользоваться и ей нужна общая история изменений.

Серверный партнёр проверяет статус. Подключает папку, меняет источник и запрашивает синхронизацию агент рабочего места через MCP. Для Drive он также создаёт и после привязки удаляет служебный файл своим инструментом записи.

Если используется хранилище ИТ-службы, её сотрудники предоставляют агенту папку, доступную для чтения; готового серверного подключения к такому хранилищу пока нет. Папку можно позже перенести между Google Диском и git, сохранив файлы.
