# Подключение Kimi к Claude Code в BB

Для нового пользователя из России рекомендуем **BB + Kimi через Claude Code**: зарубежная карта и VPN для этого пути не нужны. В BB провайдер называется **Kimi (CC)**. Если подходящий агент уже работает, сохраняем его; заново покупать подписку и менять работающее подключение не требуется.

Если выбрал Pi или Claude Code не запускается из-за ограничений компьютера, используй [Kimi через Pi](kimi-pi-bb.md). Работающий Kimi (CC) ради этого менять не нужно.

Сначала обсуди с Telegram-помощником варианты и выбери подходящий. Если уже работает Codex, Claude или другой подходящий агент, можно продолжить с ним без новой покупки. Для выбранного Kimi помощник помогает установить BB и плагин svaib, пройти встроенный настройщик и получить первый ответ модели. После этого подключение svaib продолжает агент BB. Бесплатное приложение BB само по себе не даёт доступа к модели.

## 🔹 Подписка и ключ

1. Открой международный [сайт Kimi](https://www.kimi.ai) и войди в свой аккаунт. Один из способов — Google. Настройщик использует международный API `api.kimi.ai/coding/`: нужен аккаунт и ключ Kimi Code для этого API. Если официальная ссылка или переход приведут на kimi.com, это не ошибка — страницы управления подпиской могут находиться на обоих доменах.
2. Открой [подписку](https://www.kimi.ai/membership/subscription). Настройщик использует Kimi K3.1 Pro с контекстом 1M — для него подходит **Pro** или выше. Plus тоже даёт Kimi Code, но не 1M для этой модели; Go не даёт coding-квоту. По умолчанию выбери оплату **за один месяц**. Перед оплатой проверь выбранный период, валюту и итоговую сумму на экране оформления: плата должна списываться за месяц. Если месячный вариант не виден, попроси помощника проверить, где выбирается период. Рабочую прежнюю подписку не меняй только ради названия тарифа.
3. Для оплаты картой «Мир» проверь доступный способ на сайте Kimi с российским IP и выключенным VPN. Способы оплаты зависят от региона и показываются на экране оплаты: наличие способа и успешность платежа подтверждаются там, не этой инструкцией. Если способ не появился или платёж отклонён, сообщи помощнику, что показано; не покупай другую подписку наугад.
4. В [консоли Kimi Code](https://www.kimi.ai/code/console) создай API-ключ и сохрани его локально. Нужен именно ключ Kimi Code, а не отдельного сервиса Kimi Open Platform.

Ключ вводится в защищённом поле карточки BB-плагина. Не вставляй его в Telegram, текст разговора BB, скриншот или JSON настроек провайдера.

## 🔹 Если в BB уже работает агент

Если этот доступ подходит, сохрани его и продолжи подключение svaib. Настраивай Kimi, только если выбрал добавить его. В этом случае можно открыть встроенную карточку ниже или попросить доступного агента помочь:

> Подключи Kimi через Claude Code по инструкции svaib. Сохрани действующие провайдеры и входы; ключ запроси защищённым локальным вводом.

Агент проверит текущие настройки и поможет пройти тот же встроенный маршрут с сохранением существующего доступа. Если Kimi (CC) уже работает, повторная установка не нужна. Готовность подключения svaib проверяется отдельно.

## 🔹 Настройка из интерфейса плагина

Основной путь ниже — опубликованный плагин **svaib для BB 0.7.0 или новее** со встроенной карточкой Kimi. Для установки плагина, подготовки модели и ввода ключа ещё не нужны готовый агент и вход в svaib. Версия плагина отличается от версии самого BB Desktop.

1. В BB открой **Settings → Installed plugins → New plugin → Install from source**, вставь `npm:bb-plugin-svaib-workplace` и подтверди установку. Работающий агент, Git и отдельная установка npm для этого не нужны; пакет уже собран.
2. Открой страницу svaib, нажми **«Настроить Kimi»** и выбери **Claude Code**. Вход в аккаунт svaib пока не требуется.
3. Если плагин сообщит, что не хватает Node.js, установи его с npm по показанной ссылке и нажми **«Проверить установку»**. Остальную подготовку выполняет плагин.
4. Вставь ключ из консоли Kimi Code в защищённое поле карточки и нажми **«Продолжить»**. Плагин подготовит профиль и адаптер отдельно от действующих подключений и добавит Kimi в BB.
5. Дождись автоматической проверки: плагин создаст отдельный служебный разговор, отправит короткий запрос и проверит ответ Kimi (CC) на выбранном компьютере. Самостоятельно отправлять тест не нужно. После успеха карточка подтвердит готовность; подключение svaib продолжается отдельно.

Если API добавления провайдера недоступен, карточка покажет запись без ключа и действие в ACP providers. Добавь только эту запись, сохрани остальные и нажми **«Провайдер добавлен — проверить»**. Ручная отправка запроса нужна только тогда, когда старая незавершённая карточка сама показывает поле нового разговора: проверь Kimi (CC) и компьютер и отправь предложенный короткий тест.

Если используешь другого агента, выбери **«У меня уже есть другой агент»**. **«Не сейчас»** тоже скрывает карточку. Повторное открытие — в настройках плагина, **«Настроить или проверить Kimi»**. Новый чат и перезапуск BB сами её не возвращают.

Если карточка не видна, открой её из настроек. Если и такого действия нет, проверь версию и обнови плагин из того же источника. Не переустанавливай Kimi из-за скрытой карточки. При ошибке установки продолжай с текущего шага; свой ошибочный ключ исправляй в карточке. Действующие подключения сохраняются.

## 🔹 Подключить svaib

После ответа из карточки открой обычный новый разговор BB с тем же Kimi (CC) и выбранной рабочей папкой. Служебный разговор «Проверка Kimi» ограничен коротким тестом — настройку svaib в нём не продолжай. Передай запрос Telegram-помощника в обычный разговор и продолжи по [маршруту подключения svaib](bb-svaib.md). Сохраняются доступ, профиль, исходное поручение, компания и папка; повторный тест модели не нужен.

Агент проверяет отдельно: пакет svaib для Claude Code в том же профиле Kimi, работу MCP, запуск хуков, затем пространство и знакомство. Сам по себе ответ Kimi ещё не подтверждает эти результаты.

## 🔹 Агенту: профиль и проверка

Опубликованный настройщик использует `@agentclientprotocol/claude-agent-acp@0.100.0`. Provider BB — `acp-claude-kimi`, модель сохраняет настоящий ID. Методологический пакет svaib общий для Codex и Claude Code; для Kimi (CC) выбирается CLI/profile Claude. Не подменяй provider ID на `claude-code`.

Карточка использует собственный каталог данных BB-плагина на компьютере. У подключения, настроенного раньше, каталог может отличаться; путь не угадывай. Возьми command/args действующей регистрации Kimi в BB, установи настоящий `launch.mjs` и его изолированный `CLAUDE_CONFIG_DIR`. Внутри профиля `claude/` содержит конфигурацию, `credentials.json` — закрытый ключ, `bb-agent.json` — регистрацию без секретов; ключи не читай и не выводи.

Claude CLI запускается в том же профиле: `node <проверенный абсолютный launch.mjs> --claude <аргументы CLI>`. Методологический плагин/MCP ставь через него, не через первый `claude` из PATH. Существующее средство запуска не заменяй и новый профиль молча не создавай. Успех карточки подтверждает ответ модели, а native MCP, хуки и вход в svaib проверяются отдельно.

Профиль для 1M использует `k3.1-pro[1m]`, соответствующие лимиты контекста и сжатия и сопоставление фоновых моделей. Thinking должен оставаться включённым. Настройщик получает список моделей, названия, контекст и глубину рассуждения из API Kimi; каталог не ограничен одной моделью. Совместимые новые модели появляются при обновлении каталога без нового выпуска плагина. Обновление не переключает модель открытого разговора. Число моделей не подтверждает готовность, а право на 1M зависит от подписки, не от подписи в списке BB.

## 🔹 Если что-то пошло не так

- **429:** прочитай текст ошибки. Это могут быть пять часов, месячная квота, недельная квота старого тарифа, параллельные запросы или перегрузка сервера. Extra Usage нужен при исчерпанной квоте; при перегрузке подожди и повтори, покупка не устранит перегрузку.
- **403 про модель или 1M:** проверь возможности подписки и выбранную модель; имя в BB не даёт права на неё.
- **Провайдер не появился:** проверь сохранение записи в ACP providers и завершение настройки. Не переустанавливай весь BB.
- **Модель представилась Claude:** самоописание не доказывает маршрут запроса. Агент проверяет локальный профиль и доступ к Kimi, не выводя ключ.
